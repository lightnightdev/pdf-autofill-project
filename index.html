Tips / Shortcuts

Placing a marker:
- Choose a column on the right
- Click to place a marker
- Click the column again to duplicate it

Editing a marker:
- Click an existing marker or it's column card to selected it
- Use (+/=) and (-) keys to adjust font size
- Use arrow keys to adjust the location
- Press the (Delete) key to delete that marker

Unzipping on Windows:
- Right click the file > Properties > Unblock
